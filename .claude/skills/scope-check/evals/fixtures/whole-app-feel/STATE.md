# The app today (phone)
Five tabs at the bottom (Today, Library, Practice, Progress, You). Today: a heading "Today", a caption under it, a card per lecture with a due count pill, a "Start" button per card, and a "What's fading" list below. Library: a list of classes, each opens a lecture page with a tree drawing at the top, a row of five mode buttons (Learn, Review, Practice, Test, Diagrams) each with a caption, and a list of sections. Practice: a settings form with checkboxes. Progress: charts. Every screen uses the same card component with a border; most screens have an explainer sentence under the heading. The style aims at a printed book / herbarium sheet (paper texture, serif type), but the cards and pills read like a generic web app.
