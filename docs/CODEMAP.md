# Code map

Generated by `npm run codemap` from the first sentence of each file's header
comment. Do not edit by hand: change the file's header and run it again. The
pull-request check fails when this map is out of date.

Start here to find where something lives, then open the file. What each
feature is meant to do is in `docs/EXPECTATIONS.md`; the docs are listed in
`docs/README.md`.

## src/

Entry point, router and service worker.

- `main.tsx`: The app's entry point: runs the startup watchers and migration, then mounts the router.
- `router.tsx`: Hash routing (createHashRouter) is required, not a preference — GitHub Pages serves this as a static site with no server-side rewrite, so a path-based SPA router 404s on refresh/deep-link.
- `sw.ts`: injectManifest source — see tsconfig.sw.json for this file's (WebWorker, not DOM) type scope.

## src/app/

The root layout and the error screen.

- `RootLayout.tsx`: What the running head says on the right — where in the work you are.
- `RouteError.tsx`: The error screen the router shows when a route fails, with a link back to the Library.
